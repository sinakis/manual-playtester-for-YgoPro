This is a vibe coded tool for manual testing of decks in yugioh, functionally close to the Logick LLC Yugipedia apk tool.
playtester_ygopro requires any ygopro branch on pc, preferably ProjectIgnis.

Drop playtester_ygopro.html directly into your ygopro folder.
After running playtester.html, load the ygopro folder and it will load the cdb, expansions, decks and images it needs.

playtester_YGOPRODeck.html loads all cards online from ygoprodeck.
Load or paste ydk or ydke files to it to test.
